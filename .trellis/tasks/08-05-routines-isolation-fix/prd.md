# 固定日课数据隔离修复 — 单日修改不影响全局

## Goal

修复修改一天的日课导致所有日期日课变化的 bug。日课改为每日独立副本，修改仅影响当天。与存档系统（08-05-archive-rewrite）的模板-副本分离架构一致。

## Requirements

### R1：每日独立副本
- R1.1：日课数据从全局共享改为每日独立副本
- R1.2：修改今天的日课（时长、名称、增删）仅影响今天
- R1.3：昨天/明天/任意其他日期的日课不受影响

### R2：日课模板
- R2.1：全局日课模板作为"默认预设"独立存储
- R2.2：新日期首次访问时从模板 Copy 生成当日副本
- R2.3：用户可选"推送到模板"将当天改动同步为未来默认
- R2.4：推送仅影响未来未初始化的日期

### R3：与存档系统衔接
- R3.1：日课副本在存档时随每日数据一起存入快照
- R3.2：存档后日课副本随该日数据锁定为只读

## Acceptance Criteria

- [ ] AC1：今天将"背单词"从 30 分钟改为 60 分钟 → 切换到昨天 → 昨天仍显示 30 分钟
- [ ] AC2：切换到明天（未初始化）→ 使用模板默认值（30 分钟，未受今天修改影响）
- [ ] AC3："推送到模板"后 → 新日期使用 60 分钟，已有日期的不变
- [ ] AC4：存档今天的日课后 → 修改模板 → 存档数据不变
