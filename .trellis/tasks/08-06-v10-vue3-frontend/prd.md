# Vue 3 前端重写 — 时间轴 + 任务卡片

## Goal

在 Vue 3 脚手架基础上实现时间轴主视图和任务卡片，支持日期导航、三态色彩、任务编辑、子任务划掉、导入。时间轴需有表现力（动画、状态过渡、视觉层次）。

## Requirements

### R1：时间轴主视图
- R1.1：日期导航（← 今天 →）+ 三态色彩指示
- R1.2：模式切换（完整/最低/恢复）
- R1.3：导入按钮 + 新建任务按钮 + 固定事务按钮
- R1.4：时间轴渲染 — 统一卡片列表，按时间线排列
- R1.5：任务卡片可拖拽调整顺序
- R1.6：时间起点可调整，后续时间自动重算

### R2：任务卡片
- R2.1：统一渲染（标题、icon、用时、子任务、进度条、计时器）
- R2.2：编辑按钮始终可见，弹窗编辑
- R2.3：子任务点击划掉（删除线 + 动画）
- R2.4：关联目标标签（goal badge）
- R2.5：XP 奖励显示

### R3：表现力增强
- R3.1：卡片入场动画（staggered fade+slide）
- R3.2：任务勾选完成粒子特效
- R3.3：时间三态色彩在卡片边框/日期指示器上可见
- R3.4：计时器运行中卡片呼吸边框
- R3.5：进度条颜色阈值（绿/黄/红）
- R3.6：日期切换平滑过渡

### R4：导入弹窗
- R4.1：JSON 文本输入导入
- R4.2：AI 生成导入
- R4.3：导入预览确认

## Acceptance Criteria

- [ ] AC1：时间轴渲染日期正确的任务卡片
- [ ] AC2：日期切换 → 内容平滑过渡 + 色彩变化
- [ ] AC3：编辑按钮在所有卡片上可见可点击
- [ ] AC4：子任务点击 → 删除线动画 → 进度更新
- [ ] AC5：完成任务 → 粒子特效 + XP 到账 toast
- [ ] AC6：计时器运行 → 卡片呼吸边框
