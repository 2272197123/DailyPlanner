# 任务卡片 UI 重设计 — 统一渲染+可编辑+待办划掉

## Goal

统一目标拆解任务卡片与固定日课卡片的渲染结构。所有卡片可编辑、可删除、子任务可逐条勾选划掉。修复 `generated` 标记隐藏编辑入口的 bug。

## 架构决策

### 统一卡片结构
不管来源是 AI 生成、手动创建、JSON 导入——全部使用同一套卡片渲染。通过 `kind` 标签区分来源类型，不通过隐藏功能来区分。

### 编辑弹窗双路径查找
`openTaskModal(id)` 先在 `store.tasks` 查找，未找到则在 `store.schedules[currentDate].blocks` 查找。保存时写回对应数组。

## Requirements

### R1：统一卡片渲染
- R1.1：所有任务卡片使用同一套渲染函数，不区分来源
- R1.2：卡片结构：标题行（icon + 标题 + 时长）→ 标签行（分类/优先级/关联目标/阶段）→ 说明行（可选）→ 子任务列表 → 计时器（可选）→ 进度条
- R1.3：固定事务卡片复用同一结构，通过 `kind` 标签区分
- R1.4：不使用 `generated` 或类似标记来隐藏功能入口

### R2：始终可编辑
- R2.1：编辑按钮始终显示，无论任务来源
- R2.2：删除按钮始终显示
- R2.3：编辑弹窗查找范围覆盖 `store.tasks` 和 `store.schedules[date].blocks`
- R2.4：保存时写回正确的源数组

### R3：子任务可勾选划掉
- R3.1：每条子任务点击后切换 `done` 状态，文字出现删除线
- R3.2：全部子任务完成时主任务自动标记完成

### R4：卡片与数据对齐
- R4.1：AI 返回的所有字段完整渲染，缺少字段时有合理默认值
- R4.2：不使用任何硬编码示例数据作为默认值

## Acceptance Criteria

- [ ] AC1：AI 生成的任务卡片 → 编辑按钮可见 → 点击可编辑 → 修改保存成功
- [ ] AC2：手动创建的任务卡片 → 编辑按钮可见 → 行为与 AC1 一致
- [ ] AC3：固定事务卡片 → 同样显示编辑入口
- [ ] AC4：点击子任务 → 文字出现删除线
- [ ] AC5：全部子任务勾选 → 主任务自动标记完成
