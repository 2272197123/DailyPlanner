# 记账模块重写 — 时间段筛选+饼图+条形图

## Goal

重写记账面板，支持按时间段筛选收支记录，生成饼图和条形图统计。

## Requirements

### R1：时间段筛选
- R1.1：支持快捷时间范围（本周/本月/近三月/今年）
- R1.2：支持自定义起止日期
- R1.3：筛选后实时更新数据面板和图表

### R2：数据可视化
- R2.1：饼图按分类展示支出占比
- R2.2：条形图按时间维度展示收支趋势（按周/按月可切换粒度）
- R2.3：图表使用 Canvas/SVG 渲染，不依赖外部库

### R3：记账条目管理
- R3.1：新增条目：类别（可自定义）、金额、日期、备注
- R3.2：编辑/删除已有条目
- R3.3：类别列表用户可自定义

### R4：汇总面板
- R4.1：选定时间段总收入/总支出/结余
- R4.2：支出 Top 类别排行

## Acceptance Criteria

- [ ] AC1：选择"本月" → 面板显示本月总收支 + 图表
- [ ] AC2：饼图正确反映各类别支出比例
- [ ] AC3：条形图正确反映每天/每周收支趋势
- [ ] AC4：添加一条支出 → 面板实时更新
- [ ] AC5：无硬编码支出类别（用户可自定义）
