# PRD: 成就与卡牌收集系统（稀有度抽卡 + 每日签到 + 收集页）

## 背景

增加收集乐趣与正反馈。用户决策（2026-08-16）：
- **4 个卡牌系列全做**：塔罗星象 / 美食图鉴 / 精灵宠物 / 四季节气
- 每张卡除稀有度外内置**隐藏面值**：按稀有度统一范围随机，UI 不显眼展示，为将来商城系统预留
- 稀有度：SSR 金 / SR 紫 / R 蓝 / N 白

## 需求

### 卡牌定义与掉落
- 卡牌定义库（静态数据/种子表）：每张卡有 所属系列、名称、稀有度、卡面视觉（CSS 渲染的卡框 + 图案，暂不要求逐卡美术图，用主题化 CSS 卡面 + 符号图案即可；后续可替换为生成图）
- 面值范围（隐藏，示例待设计定稿）：N 1-10 / R 5-20 / SR 15-40 / SSR 30-100
- **掉落触发**：每完成一个任务卡（计划块）随机掉落 1 张卡，稀有度权重（示例：N 55% / R 27% / SR 13% / SSR 5%，实现时可调）
- 掉卡动效：复用现有 CardCelebration/CardFlyIn 体系，新卡揭示动效按稀有度分级（SSR 最华丽）
- 取消完成**不回收**卡牌（与 XP 退还口径不同，避免收集反复横跳；XP 退还见兄弟任务 fix-xp-refund-stardial，两条链路不得互相误伤）

### 每日签到
- 每日首次进入/手动点击签到，连续签到 streak 计数
- 签到奖励：每日 1 张卡（或 XP），连续签到里程碑给高稀有度保底（如 7 天连签必出 SR+）

### 成就系统
- 成就定义（示例方向）：累计完成 N 任务、连签 N 天、集齐某系列、首张 SSR、单日完成全部任务等
- 成就达成时弹祝贺动效（复用 burst/CardCelebration）

### 收集页面
- 新页面「收集」（路由 + 侧栏入口）：按系列分组展示卡牌图鉴（已获得的亮显 + 数量，未获得的剪影/问号占位）
- 成就墙：已达成/未达成（进度条）
- 签到日历/连签展示
- 面值不显眼展示（卡面角落小字或仅在详情 tooltip）

### 后端
- 新表（三套方言 + init_mysql.sql）：`user_cards`（user_id, card_id, face_value, obtained_at, source）、`checkins`（user_id, date, streak）、`user_achievements`（user_id, achievement_id, achieved_at）
- 接口：抽卡（服务端随机，防作弊）、卡牌清单、签到、成就列表/检查
- 游客模式可用（游客数据 7 天清除的既有逻辑覆盖新表）

## 约束

- 抽卡随机在服务端做（前端不可伪造）；掉落/签到接口幂等（防重复提交）
- 卡面 CSS 遵守 chrome80 约束；掉卡/揭示动画用 transform/opacity + anime.js，reduced-motion 降级
- 移动端适配；收集页 365 格式大列表借鉴 MoodGrid 教训（不大列表 stagger、不常驻 will-change）
- 不破坏现有 XP/currency 体系

## 验收标准

1. 完成任务 → 掉卡动效 → 收集页可见新卡（系列/稀有度/隐藏面值已存库）；取消完成卡不回收、XP 正常退还
2. 稀有度权重生效（SSR 金框/紫 SR/蓝 R/白 N 视觉分级明显）
3. 每日签到 + 连签计数 + 里程碑保底；重复签到幂等
4. 成就达成有提示与记录；收集页展示图鉴 + 成就墙 + 签到状态
5. 游客与注册用户均可用；换设备（登录用户）数据保留
6. `npm run build` 通过；e2e 不回归
