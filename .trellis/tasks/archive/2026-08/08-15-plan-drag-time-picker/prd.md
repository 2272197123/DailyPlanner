# PRD: 计划块自由拖拽 + 钉时/流动互转 + 创意时间/日期设置 + 块排版强化

父任务：`.trellis/tasks/08-15-plan-interaction-and-mood-tarot/prd.md`

## 背景

计划页 v13 纵向时间轴（`FlowTimeline.vue`）目前用 HTML5 Drag & Drop 做排序，存在两个问题：

1. **移动端（触屏）完全不能拖**——HTML5 DnD 不支持触屏，用户在手机（夸克等）上无法拖拽排序。
2. **跨类型拖拽「弹回去」**——`getComputedTimeline` 把钉时块（`block.time` 非空）和流动块分开推算再按 `_startMin` 排序，流动块拖过钉时块、或拖到钉时块所在位置时，视觉上顺序不变，用户感知为「不能自由拖拽」。

同时用户要求：块排版中时间与任务名更突出（时间为主标题）；时间/日期设置弃用原生 `type="time"` 控件，改用契合画风的创意组件。

## 需求

### R1 指针事件拖拽（鼠标 + 触屏）

- 弃用 HTML5 DnD，改用 Pointer Events 自实现拖拽：按下移动超过阈值（~6px）进入拖拽，否则视为点击（保持整卡点击切换完成的现有行为，Session 6）。
- 触屏可用；拖拽时显示悬浮卡片副本（跟随指针）、插入位置指示线；到视口边缘自动滚动页面。
- 拖拽中不触发卡片点击切换。

### R2 拖拽落点语义（钉时/流动互转）

记落点为两行间间隙或直接落在某块上：

- **流动块落到流动块之间的间隙** → 纯重排：更新 `orderCfg[date].order` 并持久化（现有 `applyOrder` + `PUT /order/{date}`）。
- **流动块落到钉时块上** → 该块获得推算时间变为钉时块：时间 = 目标钉时块开始时间（若与现有钉时块冲突则顺延到其后，5 分钟取整），从流动序中移除。落在间隙一律为纯重排（含钉时块相邻间隙；钉住操作通过直接拖到钉时块身上完成，落点指示区分两种动作：📌 钉住 / ↕ 排序）。
- **钉时块拖动** → 改时间不改性质：落点推算新开始时间（取相邻块时间中点或落点映射时间，5 分钟取整，避开其他钉时块），仍为钉时块。
- 钉时块 → 流动块的转换通过编辑面板「转为流动（清除时间）」完成（见 R3），拖拽不做此转换。
- 所有变更走现有 store 持久化路径（saveDay / PUT /order），刷新后保持。

### R3 星轨轮盘时间设置（主）

- 点击卡片上的时间区域（或编辑面板中的时间字段）→ 卡片 3D 翻面（沿用 CardCelebration 的塔罗翻面视觉语言），背面为圆形轮盘：
  - 内圈小时（1–12，AM/PM 切换或 24h 双圈），星符/刻度标记；外圈分钟，拖动指针，5 分钟吸附。
  - 确认时有星尘粒子反馈；提供「钉住时间」「转为流动」两个动作按钮。
- 指针拖动用 Pointer Events，触屏可用；不能用原生 `type="time"`。

### R4 星图拖杆（辅）

- 编辑面板中提供迷你 24h 横轴：已有钉时块显示为星座标记，拖动手柄设定开始时间；拖到钉时块附近磁吸避让；松手粒子反馈。
- 与轮盘二者数据同步（同一 `time` 值）。

### R5 星历横条日期设置

- 新增/编辑任务的日期选择改为横向惯性滚动日条：每天一格星座符号 + 日期数字，今天发光标记，两侧渐隐；支持惯性物理滚动。
- 月相元素搭配：日条头部显示当月月相图标装饰。
- 编辑已有块时改日期 = 把块移动到另一天（从原 date 移除、加入目标 date，两边都持久化）。

### R6 块排版强化

- 时间为主标题：块内时间（如 `09:00–10:30`）用大号等宽字体独立醒目展示，任务名加粗紧随，分类 emoji 缩小作点缀。
- 新建任务 modal（`PlanView.vue` 内联表单）中的 `type="time"` 输入替换为星轨轮盘组件。
- 编辑面板（`TaskCard.vue` edit 表单）同样替换。

## 验收标准

- A1：桌面鼠标与移动触屏（CDP 模拟触摸）均可拖动流动块重排，刷新后顺序保持。
- A2：流动块拖到钉时块上 → 变为钉时块且时间正确（冲突顺延）；钉时块拖动 → 时间更新；编辑面板「转为流动」→ 回到流动序。
- A3：新建 modal 与编辑面板均无原生时间/日期控件；轮盘可拖动设置时间，星图拖杆同步；星历横条可换日期并把块移到目标日。
- A4：块排版：时间为视觉主标题；9 主题 × 亮暗模式下可读。
- A5：`npm run build` 通过；无 color-mix / 现代媒体查询等 chrome80 不兼容语法；移动端 ≤390px 无横向溢出。
- A6：整卡点击切换完成、计时器按钮等既有交互不回归（CDP 验证）。

## 非目标

- 不改周期规则物化逻辑；不动 CardCelebration / CardFlyIn 既有动效。
- 不做多天批量拖拽。
