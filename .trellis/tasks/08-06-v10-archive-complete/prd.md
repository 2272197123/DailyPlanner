# 存档系统补全 — 真PDF导出+AI人设UI+存档评价主视图可见+反馈整合

## Goal

补全 v9.0 存档系统遗留缺口，并将存档流程与今日反馈板块整合为统一的"每日复盘"入口。存档后形成不可修改的每日快照（含自评+AI评价+任务明细+统计），在主时间轴视图中可见。

## 核心设计决策：反馈 + 存档 = 每日复盘

当前反馈区（💭 今日反馈 + ★ 星级评分）和存档流程（自评+AI评价）是割裂的。合并为统一的**每日复盘面板**：

- 用户可随时写反馈、打分
- 到达存档时间（默认 23:30）后，提示完成复盘
- 一键存档：自评文字 + 星级 + AI 评价 + 任务统计 → 生成每日快照
- 存档后该日期锁定只读
- 导航到历史日期 → 底部显示该日的复盘数据（自评+AI评价+统计）

## Requirements

### R1：每日复盘面板（合并反馈+存档）
- R1.1：底部反馈区升级为"每日复盘卡片"，包含：文字反馈、星级评分、存档按钮、AI评价触发按钮
- R1.2：存档时间可配置（可在设置中修改）
- R1.3：到达存档时间后，如果当天未存档，高亮提示
- R1.4：存档后该组件自动切换为只读复盘视图

### R2：存档快照
- R2.1：存档时生成完整快照（blocks + routines + routineProgress + 自评 + AI评价）
- R2.2：快照独立存储（localStorage + 服务器 `PUT /api/day-data/{date}`）
- R2.3：存档后当日数据锁定，不可编辑

### R3：AI 评价
- R3.1：存档时可请求 AI 生成评价
- R3.2：AI 人设 prompt 在设置中可编辑（提供 UI 入口）
- R3.3：AI 评价内容随快照永久保存

### R4：历史复盘查看
- R4.1：导航到历史存档日期 → 底部复盘面板显示该日快照内容
- R4.2：显示：自评文字 + 星级 + AI 评价 + 完成统计
- R4.3：历史日期不可编辑

### R5：导出
- R5.1：支持导出 Markdown（自评 + AI评价 + 任务明细 + 统计）
- R5.2：支持导出 PDF（服务端生成真 PDF）

## Acceptance Criteria

- [ ] AC1：写反馈+打分→点存档→快照生成→锁定今天→底部显示复盘数据
- [ ] AC2：导航到已存档日期→底部显示自评+AI评价+统计→时间轴只读
- [ ] AC3：设置中修改 AI 人设 prompt→存档→AI 评价风格变化
- [ ] AC4：修改存档时间→到达修改后的时间→系统提示存档
- [ ] AC5：导出 MD→内容完整
- [ ] AC6：控制台零报错
