# AI 交互流程重写 — 多轮对话+目标拆解+每日任务动态调整

## Goal

将 AI 交互从"单次模板发送→返回JSON→直接导入"改为集中式对话面板。用户和 AI 可反复讨论目标拆分与每日任务，预览编辑后再确认导入。长线目标状态作为结构化数据每次注入，不依赖对话历史防遗忘。

## 架构决策

### 面板形态：BT 式搭档抽屉

- 日常隐藏，右下角悬浮按钮触发
- 右侧滑入抽屉面板（桌面端 ~380px），推挤主时间轴，不覆盖内容
- 快捷键 Shift+Space 开/关
- AI 有新消息时，悬浮按钮呼吸光效
- 用户可选"钉住"持久展开
- 小屏自动切换全屏 overlay

### AI 上下文：一个面板，两个上下文档位

不拆成两个 AI——同一个入口、同一个人设 prompt。每次请求前，系统根据意图自动打包不同的上下文数据包：

| 意图 | 注入数据 | Token 预算 |
|------|---------|-----------|
| 讨论目标/策略 | 所有活跃目标完整结构、阶段、里程碑、截止日期、最近调整记录 | ~800 tokens |
| 生成每日任务 | 当前阶段+未完成里程碑、今日已有任务+用时、昨日未完成项、剩余天数、每日时间上限 | ~500 tokens |

上下文包从前端 `store.bigGoals` 实时读取，不翻旧聊天记录。

## Requirements

### R1：集中式 AI 对话面板
- R1.1：单一入口——右下角悬浮按钮 + 快捷键 Shift+Space
- R1.2：右侧滑入抽屉，推挤主时间轴
- R1.3：对话面板包含：消息列表、输入框、发送按钮、清空按钮
- R1.4：支持键盘发送（Enter，Shift+Enter 换行）
- R1.5：AI 思考时显示动画状态，禁用输入
- R1.6：用户名使用 `{user}` 占位引用，不使用具体示例名

### R2：目标讨论与拆解
- R2.1：用户通过自然语言描述目标，AI 引导澄清后拆解为阶段+里程碑
- R2.2：拆解结果以可编辑预览卡片形式展示，用户可修改各字段
- R2.3：确认后导入为正式目标（写入 store.bigGoals + 服务器）
- R2.4：支持反复讨论修改——AI 记住当前讨论中的临时拆解结果
- R2.5：所有示例使用参数化描述，如 `{目标名称}`、`{截止日期}`，不出现真实数据

### R3：每日任务生成
- R3.1：用户可请求 AI 为某日期生成每日任务
- R3.2：生成前自动注入：当前目标阶段、未完成里程碑、该日已有任务、时间上限
- R3.3：生成结果以可编辑任务卡片列表展示（标题、用时、说明、子任务，均可编辑）
- R3.4：用户确认后导入时间轴，去重合并
- R3.5：支持对已生成结果进行二次对话修改

### R4：动态调整与顺延
- R4.1：未完成任务自动检测——今天有任务未完成时，提示用户处理
- R4.2：用户可选择：顺延到明天 / 顺延并增加后续每日工作量 / 放弃
- R4.3：有硬截止日期的目标，顺延时计算剩余天数并重分配工作量
- R4.4：无截止日期的目标，单纯后移不做额外调整

### R5：上下文防遗忘
- R5.1：每次 AI 请求携带目标结构化快照（从 store.bigGoals 实时读取）
- R5.2：约每 10 轮对话自动压缩旧消息为摘要
- R5.3：用户可随时手动清空对话历史
- R5.4：对话历史持久化到 localStorage，刷新不丢失

### R6：API 配置
- R6.1：支持配置 API Key、Base URL、模型名
- R6.2：前端直连优先，CORS 失败时回退服务端代理
- R6.3：每次请求记录 token 消耗和耗时
- R6.4：无 API Key 时面板显示配置引导

## 数据流

```
用户输入
  │
  ▼
系统打包上下文包（从 store.bigGoals + store.schedules 读取）
  │
  ▼
组装 messages（system prompt + 上下文包 + 对话摘要 + 历史消息）
  │
  ▼
调用 DeepSeek API（或其他配置的 API）
  │
  ▼
解析返回内容 → 可编辑预览（不直接导入）
  │
  ▼
用户确认 → 导入 store + LS + 服务器
```

## Acceptance Criteria

- [ ] AC1：点击悬浮按钮 → 右侧滑入 AI 面板，时间轴推挤缩窄
- [ ] AC2：用户描述目标 → AI 引导讨论 → 拆解结果可编辑预览 → 确认后写入 store.bigGoals
- [ ] AC3：请求生成每日任务 → AI 返回可编辑任务列表 → 用户修改时长后采纳 → 时间轴出现任务
- [ ] AC4：对已生成结果发送修改指令 → AI 修改预览内容 → 预览更新
- [ ] AC5：存在昨日未完成任务 → 打开 AI 面板有提示 → 选择顺延 → 任务调度至今日
- [ ] AC6：修改目标 deadline → 下次 AI 调用自动携带更新后的数据
- [ ] AC7：清空对话历史 → AI 上下文重置，但目标数据不受影响
- [ ] AC8：AI 面板中不出现旧项目遗留的硬编码数据

## Out of Scope

- 虚拟形象/电子宠物接入（预留接口，不做实现）
- 多 API 提供商并行（先支持单个可配置的）
- AI 生成过程中的流式输出（先做完整返回）
- 离线 AI（需要 API 连接）
