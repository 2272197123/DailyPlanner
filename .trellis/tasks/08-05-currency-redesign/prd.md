# 货币系统重设计 — 经验值+主题皮肤保留扩展

## Goal

推倒晶圆（円）系统，改为经验值（XP）累计体系。不与任务完成硬绑定，独立于任务系统运作。保留全部主题皮肤功能并扩展。

## Requirements

### R1：经验值系统
- R1.1：改为经验值（XP）+ 等级制，移除晶圆（円）概念
- R1.2：XP 获取来源可配置（完成任务 / 连续打卡 / 存档 / 其他成就）
- R1.3：等级体系：Lv.1 ~ Lv.N，每级所需 XP 可配置
- R1.4：余额唯一写入点不变（`addXP()` / `setXP()`）

### R2：与任务系统解耦
- R2.1：任务不显示奖励金额，任务与货币不绑定
- R2.2：删除 taskReward 相关逻辑（`calcTaskReward` / `awardTaskReward` / `ROUTINE_REWARD`）
- R2.3：XP 获取由独立的成就/事件系统触发

### R3：主题皮肤保留与扩展
- R3.1：保留全部 6 套主题：sakura / forest / ocean / sunset / noir / vapor
- R3.2：用户可自定义主题的 CSS 变量（颜色/字体/图案）
- R3.3：新增至少 2 套主题
- R3.4：主题切换预览功能

### R4：流水记录
- R4.1：保留交易流水，格式从"晶圆"改为"XP"
- R4.2：流水记录 XP 变化原因 + 时间戳

## Acceptance Criteria

- [ ] AC1：界面显示 XP + 等级，不再显示晶圆（円）
- [ ] AC2：完成任务后不再弹出晶圆奖励
- [ ] AC3：全部 6 套旧主题 + 2 套新主题可切换
- [ ] AC4：用户可修改主题的颜色变量，预览实时生效
- [ ] AC5：不出现 `WAFER_VALUE` / `WAFER_SKINS` / `ROUTINE_REWARD` 等旧常量引用
