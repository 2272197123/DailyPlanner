# 计时器 UI 优化 — 任务计时交互与视觉改进

## Goal

保留任务计时的核心能力（主计时器 + 子任务计时器），优化 UI 交互和视觉表现。提升操作手感。

## Requirements

### R1：计时器 UI 内嵌卡片
- R1.1：计时器作为卡片内嵌组件，不占用额外空间
- R1.2：显示格式 HH:MM:SS，运行中绿色脉冲指示
- R1.3：主任务计时器和子任务计时器统一在一行

### R2：交互优化
- R2.1：点击 ▶ 开始计时（快速启动，无多余确认）
- R2.2：点击 ⏸ 暂停计时
- R2.3：点击 ↺ 重置计时（保留完成记录，仅回零）
- R2.4：快捷键支持（Space 切换开始/暂停，当前选中的卡片）

### R3：子任务独立计时
- R3.1：每条子任务独立计时，互不干扰
- R3.2：子任务计时与主任务计时叠加显示
- R3.3：子任务完成后自动停止其计时器

### R4：数据持久化
- R4.1：计时器状态刷新不丢失（已有的 `dp_timers` / `dp_stTimers` 存储）
- R4.2：实际用时记录保留，用于后续复盘

## Acceptance Criteria

- [ ] AC1：点击任务卡片 ▶ 按钮 → 计时器开始走动
- [ ] AC2：刷新页面 → 计时器状态保留
- [ ] AC3：子任务勾选完成 → 其计时器自动停止
- [ ] AC4：计时器运行时有视觉脉冲指示
