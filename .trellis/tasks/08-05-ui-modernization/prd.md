# 整体 UI 现代化 — 简化交互+修复外露源码+视觉升级

## Goal

全局 UI 现代化：时间三态视觉分区、日期切换翻页动画、弹窗与面板规范化、输入区域扩大、外露源码修复、设计系统基线适配。

## Requirements

### R1：时间三态视觉分区
- R1.1：历史已存档日期 → 暖琥珀色调，锁定标识，纯只读
- R1.2：今天 → 靛蓝墨主色，全功能活跃态
- R1.3：未来日期 → 冷淡紫色调，虚线卡片边缘，可规划
- R1.4：色调切换通过 CSS 变量实现，不硬编码颜色值

### R2：日期切换动画
- R2.1：日期切换时淡入淡出动画（~400ms）
- R2.2：时间轴内容先淡出 → 日期指示器变换 → 新内容淡入
- R2.3：跨多天跳转动画更短（~250ms）

### R3：弹窗规范化
- R3.1：所有弹窗统一动画系统（复用已有 overlay-anim.js 模式）
- R3.2：弹窗内容区域不能外露 HTML/JS 源码
- R3.3：关闭按钮位置一致（右上角 ✕）

### R4：输入体验优化
- R4.1：AI 对话输入框高度可调整，最小 2 行
- R4.2：所有文本输入框支持 Enter 提交
- R4.3：弹窗输入框自动聚焦

### R5：设计系统基线与清理
- R5.1：氛围元素保留且不可移除：光晕球体、宣纸纹理、墨色虚光、朱砂印章
- R5.2：字体：Noto Serif SC（标题）+ JetBrains Mono（数据）+ 系统无衬线（正文）
- R5.3：主色 `--accent: #1e2030`（靛蓝墨）
- R5.4：不使用 `transition: all`
- R5.5：移除所有旧版配色引用（`#2b3a5c` / `#4F46E5`）
- R5.6：清理 `loadTemplate()` 等函数中的示例数据模板为参数化描述

### R6：顶部导航栏日期导航
- R6.1：日期导航栏支持左右箭头 + 日期选择器
- R6.2：快速跳转到今天
- R6.3：显示当前日期的状态标签（今天/已存档/计划中）

## Acceptance Criteria

- [ ] AC1：导航到历史已存档日期 → 暖琥珀色调，所有编辑按钮 disabled
- [ ] AC2：导航到今天 → 靛蓝墨色，全功能可用
- [ ] AC3：导航到未来日期 → 淡紫色调，可编辑计划
- [ ] AC4：日期切换有淡入淡出动画
- [ ] AC5：所有弹窗不显示源码/Markdown/JSON 原生内容
- [ ] AC6：AI 输入框至少 2 行，可按 Shift+Enter 换行
- [ ] AC7：设计系统氛围元素（光晕、纹理、虚光、印章）完整渲染
