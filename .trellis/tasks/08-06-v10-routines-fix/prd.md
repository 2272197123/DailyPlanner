# 日课数据隔离修复 — 推送到模板+已初始化日期可编辑

## Goal

修复 v9.0 日课数据隔离的三个核心缺口：(1) 实现"推送到模板"功能，(2) 支持编辑特定日期的日课副本，(3) 删除日课仅影响每日副本不污染全局模板。

## Requirements

### R1：推送到模板
- R1.1：用户编辑当日日课后，可通过按钮将当天改动同步到全局模板
- R1.2：推送仅影响未来未初始化的新日期
- R1.3：已初始化的历史日期不受推送影响

### R2：每日副本可编辑
- R2.1：日课面板修改保存时，仅写入当前日期的每日副本
- R2.2：全局模板独立存储，不在每日编辑时自动修改
- R2.3：新日期首次访问时从模板 Copy 生成当日副本

### R3：删除不污染全局
- R3.1：时间轴中日课删除操作仅从当日副本移除
- R3.2：全局模板不受单日删除影响

## Acceptance Criteria

- [ ] AC1：编辑今天日课→切换到昨天→昨天日课不变
- [ ] AC2："推送到模板"后→跳到未访问的未来日期→确认使用新模板
- [ ] AC3：从时间轴删除一个固定事务→切换到其他日期→其他日期仍有该事务
- [ ] AC4：首次访问新日期→日课列表与全局模板一致
